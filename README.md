# video-script-Ying_gengrator
本项目是基于 Streamlit 搭建的 AI 短视频脚本生成网页工具，依托 LangChain 框架与阿里云百炼通义大模型实现内容创作。用户在可视化页面输入 API 密钥、视频主题、视频时长与创意参数，点击生成按钮即可自动产出短视频脚本。程序首先调用大模型生成吸睛视频标题，同时检索维基百科获取主题参考资料，随后结合标题、时长要求与检索素材，按照开头、中间干货、结尾的短视频结构生成轻松年轻化的完整脚本。系统内置参数校验，防止空输入引发异常，生成结果分区展示标题、正文脚本，并支持折叠查看维基百科参考素材。整套工具采用 LCEL 链式调用实现提示词与大模型串联，借助 OpenAI 兼容协议对接阿里云大模型，无需复杂部署。适合短视频创作者快速批量产出文案，降低脚本创作门槛，网页交互简单易用。
